# SAP MB52 Warehouse Stock Report Explanation (`mb52.XLSX`)

Comprehensive documentation and data explanation for the SAP **MB52** stock report extract (`mb52.XLSX`). This dataset represents real-time plant and storage-location-level inventory across primary warehouses and production sites.

---

## 1. File Overview & Key Dimensions

- **Source System:** SAP ERP (Transaction Code: `MB52` - *Warehouse Stocks on Hand*)
- **Total Records:** `2,123` rows
- **Total Columns:** `24` columns
- **Unique Articles / Materials:** `1,295` SKUs
- **Operating Sites / Plants:**
  - `9101` (KSA Main Plant / DC): **1,404 rows** (Currencies in SAR)
  - `1888` (Kuwait Manufacturing / Assembly Plant): **544 rows**
  - `1111` (Kuwait Main Central Distribution Center): **173 rows** (Currencies in KWD)

## 4. Operational Role in Dashboard Integration

1. **Current Physical Inventory Verification:**  
   Cross-referenced against the commercial TIM master file (`OH Stock`) to distinguish **cataloged items** from **site-specific physical bin stocks**.
2. **Quality & Blocked Inventory Monitoring:**  
   Identifies unusable stock (`Blocked` = 36.7k units) so planners do not mistakenly rely on defective or quarantined stock for production and customer order fulfillment.
3. **Multi-Site Inventory Balancing:**  
   Facilitates balancing between Kuwait (`1111`, `1888`) and Saudi Arabia (`9101`) through visibility into cross-site transit (`Stock in Transit`).
